## 📌 Übersicht

Der **Klausurtimer** wurde speziell für Lehrkräfte entwickelt, um während Schulaufgaben, Klausuren, Proben oder Stillarbeitsphasen für maximale Transparenz und Ruhe im Raum zu sorgen. Alle relevanten Regeln und die Restzeit werden gut lesbar an die Wand projiziert.

---

## ✨ Features

- **⏱️ Flexible Prüfungszeit:** Frei wählbare Dauer in Minuten (z. B. 45, 60, 90 min) mit präziser Restzeitanzeige (`MM:SS`).
- **📋 Klickbare Prüfungsregeln:** Vorlagen für typische Klausurregeln, die sich per Klick vorab aktivieren oder deaktivieren lassen:
  - *Keine Uhren / Kein Rotstift*
  - *Alle technischen Geräte ausschalten und verstauen*
  - *Kein Essen und Trinken am Platz*
  - *Nur benötigtes Schreibmaterial – kein Mäppchen*
  - *Keine Fragen, wenn die Zeit läuft*
  - *Gerne auch Rückseite verwenden / Leserlich schreiben*
  - *Zusatzzeit bitte melden*
- **📝 Eigene Notizen:** Freitextfeld für fachspezifische Hinweise (z. B. *„Formelsammlung S. 12–15 erlaubt“*).
- **⚡ Live-Steuerung während der Prüfung:**
  - Pause & Fortsetzen
  - Zeitkorrekturen (`+ 1 min`, `- 1 min`)
  - Schnelle Zeitzuschläge (`+10%`, `+20%`) für Nachteilsausgleich
- **🔒 100% DSGVO-konform & Offline-fähig:**
  - Keine Cookies, keine Tracker, keine externen Server-Aufrufe.
  - Funktioniert vollständig ohne Internetverbindung direkt im Browser.
- **🖥️ Beamer- & Whiteboard-optimiert:** Hoher Kontrast, große Ziffern und freundlicher Motivations-Avatar.

## 🚀 Schnellstart

1. Repository klonen oder als ZIP herunterladen:
   ```bash
   git clone https://github.com/ddesignmedia/Klausurtimer.git
   ```
2. Datei `index.html` mit einem beliebigen Browser (Chrome, Firefox, Safari, Edge) öffnen.
3. Dauer einstellen, gewünschte Regeln anklicken und **„Timer starten“** wählen.
